# Tack's core terms as a domain model

The terms of `CONTEXT.md` that decide what an agent ends up with, as entities and the verbs between them. Point at an entity to see what it relates to.

<Schema

  title="A resource reaches an agent only through a declaration, a selection and a managed link"

  rule={{ title: "Read the verbs along the lines", text: "A crow's foot marks the many end of a relation; a bar marks the one end." }}
  startWith={["Resource", "Selection"]}

    { name: "Source", columns: [{ name: "label" }, { name: "maintainers" }] },

A source's authors decide what exists. The operator decides what is chosen, and Tack derives the selection and the links from those choices.
