# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull requests or discussions.

Report them privately through GitHub instead:

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Describe the issue, the affected version (`tack --version`), and the steps to reproduce it.

The report stays private between you and the maintainers until a fix is published. You will get a reply in the advisory thread, and you are credited in the published advisory unless you ask not to be.

## Supported versions

Security fixes go into the latest release of `@tackup/cli`. Upgrade to it before you report, in case the issue is already fixed.
