# pr-assets

Screenshots and media for Tack pull requests. Media for PR `<number>` goes under `pr-<number>/`.

- This branch is never merged into `main` and never deleted.
- Add files as new commits on top. Never rewrite history or force-push.
- Link files from PR bodies with commit-pinned URLs:
  `https://github.com/nclsndr/tack/blob/<commit-sha>/pr-<number>/<file>?raw=true`
