# Tack docs

Tack links the skills, commands and docs you maintain wherever your coding agents look. Your files
stay in folders you own. Each agent gets a symbolic link back to them, for you and for every
project and worktree.

## What Tack manages

| Resource | Delivered to                                                                              |
| -------- | ----------------------------------------------------------------------------------------- |
| Skills   | Claude Code, Codex, Cursor, GitHub Copilot CLI, Gemini CLI, Cline, Junie, OpenCode and Pi |
| Commands | Cline, Cursor, Junie, OpenCode and Pi                                                     |
| Docs     | A local browser reader and `tack docs search`                                             |
| Scripts  | `tack script run`, with declared secrets and history                                      |

Context is catalogued but no agent delivers it yet.
