# Tack docs

Tack is an open-source CLI that combines the agent skills, commands, docs and scripts in the folders
and Git repositories you and your team own into one setup, links it into every coding agent, project
and Git worktree, and shows every change before it writes. It links skills into Claude Code, Codex, Cursor, GitHub
Copilot CLI, Gemini CLI, Cline, OpenCode and Pi. Each agent gets a symbolic link back to your
files, which stay where they are.

## What Tack manages

| Resource | Delivered to                                                                       |
| -------- | ---------------------------------------------------------------------------------- |
| Skills   | Claude Code, Codex, Cursor, GitHub Copilot CLI, Gemini CLI, Cline, OpenCode and Pi |
| Commands | Cline, Cursor, OpenCode and Pi                                                     |
| Docs     | A local browser reader and `tack docs search`                                      |
| Scripts  | `tack script run`, with declared secrets and history                               |

Context is catalogued but no agent delivers it yet.
