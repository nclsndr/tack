# Tack docs

Tack links the skills, commands and docs you maintain into Claude Code, Codex and Cursor. Your files
stay in folders you own. Each agent gets a symbolic link back to them, for you and for every
project and worktree.

## What Tack manages

| Resource | Delivered to                                         |
| -------- | ---------------------------------------------------- |
| Skills   | Claude Code, Codex and Cursor                        |
| Commands | Cursor                                               |
| Docs     | A local browser reader and `tack docs search`        |
| Scripts  | `tack script run`, with declared secrets and history |

Context is catalogued but no agent delivers it yet. OpenCode and Pi are specified, not built.
