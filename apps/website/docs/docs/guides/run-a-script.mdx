# Run a script

A script is a TypeScript file in a source that you, or your agent, run by name in any registered
project. Each run gets a fresh worker, only the secrets the script declares, and a record in the
history. Scripts are never linked into agent folders, so they need no sync.

This guide adds the script `todo-report` to `~/agent-setup` and runs it in the project `app`.

## 1. Write the script

A script default-exports one `defineScript` definition. Tack provides the `@tackup/cli` import when
it runs the script: never install it in the source.

```ts
// ~/agent-setup/scripts/todo-report.ts
import { defineScript } from "@tackup/cli";

export default defineScript({
  args: {
    tag: { type: "string", default: "TODO", description: "The marker to look for" },
    limit: { type: "number", default: 10, description: "How many comments to list" },
  },
  secrets: ["ISSUE_TOKEN"],
  run: async ({ args, secrets, fs, log }) => {
    const files = await fs.list("src/**/*.ts");
    const found: string[] = [];
    for (const file of files) {
      const lines = (await fs.read(file)).split("\n");
      lines.forEach((line, index) => {
        if (line.includes(args.tag)) found.push(`${file}:${index + 1} ${line.trim()}`);
      });
    }
    log.info(`Found ${found.length} ${args.tag} comments; token ${secrets.ISSUE_TOKEN}`);
    return { count: found.length, comments: found.slice(0, args.limit) };
  },
});
```

The `run` function gets the checked `args`, the declared `secrets`, a `log`, `fs` and `exec` that
work from the project's root, and a `fail` for an error the person should read. This script logs its
token only to show that Tack hides it.

## 2. Declare it

Add the script to the source's `tack.yaml` by hand, with a name, its path and a description:

```yaml
scripts:
  - name: todo-report
    path: scripts/todo-report.ts
    description: List the TODO comments in the project.
```

Run `tack check ~/agent-setup` to confirm it is catalogued.

## 3. Give your editor the types

`tack types` previews the types of the script API this Tack provides, and a `tsconfig.json` when
the source has none. Run it from the source folder:

<Terminal commands={["tack types"]} output={typesOutput} />

Apply it with `tack types --apply`, commit both files, and run it again after you upgrade Tack.

## 4. Look before you run

`tack script show` loads the script in a worker, without running it, and prints its arguments and
secrets:

<Terminal commands={["tack script show todo-report"]} output={showOutput} />

## 5. Give it its secret

A declared secret comes from `TACK_<NAME>`: the environment of the command, or else the `.env` file
in Tack's state folder, `~/.tack/.env`. Without it the run stops before the script starts:

<Terminal commands={["tack script run todo-report --project app"]} output={missingOutput} />

Add the value to `~/.tack/.env`:

```sh
TACK_ISSUE_TOKEN=example-token-123
```

## 6. Run it

Pass the script's arguments after `--`. The script's log lines come first, on standard error, then
the result. The token shows as `<redacted>` in logs, results and history:

<Terminal
  commands={["tack script run todo-report --project app -- --limit 1"]}
  output={runOutput}
/>

Tack checks every argument before the script runs, and reports every problem at once:

<Terminal
  commands={["tack script run todo-report --project app -- --limit many --colour red"]}
  output={invalidOutput}
/>

`--input-json '{"limit":1}'` passes the same arguments as JSON, and `--timeout 30000` stops a run
after 30 seconds and waits for its cleanup.

A run has one folder to work in. Once the project has several worktrees, `--project app` stops with
`run_target_not_unique`: name the worktree with `--root ~/code/app` instead, or run the script from
inside the worktree with no target flag.

## 7. Read the history

Every run, failed or not, is on record with its input, logs and outcome:

<Terminal commands={["tack script history"]} output={historyOutput} />

`tack script history show RUN_ID` prints one run in full. `tack script history clear` previews
deleting the records, and `--apply` deletes them.
