# Remove a source, a project or Tack

Removing is a preview first, like every change to links. Tack removes only the links it made and
its own records. It never deletes a source folder, a repository or a file you made.

This guide uses a machine with Claude Code and Codex, the sources `agent-setup` and `acme`, and the
project `app`.

## Remove a source

`tack source remove` names the source by its label. The preview lists every link Tack made for its
skills and commands, in every project and in your user folders, its docs mounts, and the picks and
docs attachments that name it:

<Terminal commands={["tack source remove acme"]} output={sourcePreviewOutput} />

Apply it with `tack source remove acme --apply`. The folder `~/code/acme-agent-skills` stays; delete
it yourself if you no longer want it.

A source whose folder is gone has no label: use its ID from `tack source`. The preview also names
any registered source that still lists the removed one under `depends-on`, because the skills that
need it stop working.

A project that runs a fixed profile with members from the source keeps the profile: the preview
marks it `! keep` and lists the members that no longer resolve, and `tack doctor` then fails its
`profiles` check. Apply a profile without those members first, with `--force`, or remove that
project.

To keep a source but stop one project from using it, exclude its skills there instead, as
[Choose what each project gets](./choose-skills) shows.

## Remove a project

`tack project remove` previews removing the links in every worktree of the project, its docs mounts,
its picks and its docs attachments:

<Terminal commands={["tack project remove app"]} output={projectPreviewOutput} />

<Terminal commands={["tack project remove app --apply"]} output={projectApplyOutput} />

The repository and its worktrees stay as they are. A single worktree you deleted leaves through
`tack project refresh --apply` instead.

## Remove an agent

`tack adapter disable` removes every link of one agent; see
[Add or turn off an agent](./agents#turn-an-agent-off).

## Leave Tack

`tack state reset` previews removing every link Tack made, at user level and in every project,
then all of its state: sources, projects, picks and script history. Your source folders and
repositories stay.

<Terminal commands={["tack state reset"]} output={resetOutput} />

Apply it with `tack state reset --apply`, then uninstall the package with the package manager that
installed it, such as `npm uninstall --global @tackup/cli`.

Two things stay. `~/.tack/.env` keeps the script secrets you put there: delete it yourself. The
agent folders Tack created, such as an empty `~/.agents/skills`, stay too, and a later `tack init`
treats a folder like `~/.agents` as a sign that the agent is installed.

## When a link cannot be removed

Tack never removes a link by force. When it cannot remove one safely, such as a link whose parent
folder was replaced, the link stays on record as a pending removal: `tack status`, `tack sync` and
`tack doctor` report it, and `tack state clean --pending --project app` previews another attempt.
A project with a pending removal stays registered until it settles.
