# Add or turn off an agent

Tack links your skills into each agent it has an adapter for: Claude Code (`claude`), Cline
(`cline`), Codex (`codex`), GitHub Copilot CLI (`copilot`), Cursor (`cursor`), Gemini CLI
(`gemini`), OpenCode (`opencode`) and Pi (`pi`). `tack init` enables the ones whose folder it finds
in your home. Turn one on or off at any time; the [features reference](../features#agents) lists
each adapter's folders.

This guide uses a machine where Claude Code and Codex are enabled, with the project `app`.

## See what is enabled

<Terminal commands={["tack adapter"]} output={listOutput} />

## Add an agent

Enabling an adapter saves at once and links nothing:

<Terminal commands={["tack adapter enable opencode"]} output={enableOutput} />

`tack sync --all` then previews every link the new agent needs: the project's skills and commands,
and in your user folders Tack's built-in skills and your user picks. The agents you already had are
up to date.

<Terminal commands={["tack sync --all"]} output={syncOutput} />

Apply it with `tack sync --all --apply`. OpenCode takes commands, so it also gets `ship`.

Name several adapters at once, such as `tack adapter enable opencode pi`. To link for one adapter
only, once, without enabling it, pass it to the sync: `tack sync --adapter claude --user --apply`.

## Turn an agent off

Disabling an adapter previews removing every link Tack made for it, at user level and in every
project:

<Terminal commands={["tack adapter disable opencode"]} output={disableOutput} />

Apply it with `tack adapter disable opencode --apply`. Tack removes only links it made: a skill you
put in the agent's folder by hand stays. An agent can still see a skill through another agent's
folder, such as OpenCode reading `.claude/skills`.

## Agents without an adapter

Many agents read `.agents/skills`, which the Codex adapter fills, or `.claude/skills`, which the
Claude Code adapter fills. Enable that adapter and they get your skills, but not your commands. The
[features reference](../features#more-agents-through-folders-they-share) lists them, with the ones
that read only a project's folder or only your home's.
