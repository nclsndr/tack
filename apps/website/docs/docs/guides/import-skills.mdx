# Import skills from GitHub

`tack import add` copies skills you choose from a GitHub repository into a source you own. From then
on the copy is an ordinary skill of that source: you edit it, commit it and sync it like any other.
Tack records where it came from in the source's `tack.yaml`, so it can tell later whether you
changed it. It is the only Tack command that reaches the network.

This guide imports the `pdf` skill from the public repository `anthropics/skills` into
`~/agent-setup`.

## 1. See what a repository offers

Name the location with its provider, `github:`. Without `--into`, Tack lists the skills it found and
whether each one would load:

<Terminal commands={["tack import add github:anthropics/skills"]} output={listOutput} />

A location can name a folder, `github:org/repo/folder`, or a branch, tag or full commit,
`github:org/repo#v1`. A private repository uses your own Git credentials; Tack reads no token.

## 2. Preview the copy

Choose skills with `--skill`, repeatable, or `--all`, and name the source with `--into`. The preview
marks the chosen skill with `✓` and one that would not load with `✗`, with the reason. It also says
where the skill will reach at the next sync. The list is cut short here:

<Terminal
  commands={["tack import add github:anthropics/skills --skill pdf --into agent-setup"]}
  output={previewOutput}
/>

`agent-setup` has one skills folder, so `--into agent-setup` picks it. A source with several needs
the folder too, such as `--into agent-setup:skills`.

## 3. Apply it

<Terminal
  commands={[
    "tack import add github:anthropics/skills --skill pdf --into agent-setup:skills --apply",
  ]}
  output={applyOutput}
/>

Tack wrote the folder `skills/pdf` and an `imports` record in `tack.yaml`; it wrote nothing into its
own state and linked nothing. Commit both in your source, then deliver the skill:

```sh
tack sync --all
tack sync --all --apply
```

## 4. Keep track of it

`tack import` lists every imported skill, its origin, and whether you changed it since:

<Terminal commands={["tack import"]} output={importsOutput} />

To delete an imported skill and its record, preview `tack import remove agent-setup:pdf`, then add
`--apply`. A skill you changed needs `--force`, and the preview lists what you would lose. The next
sync removes its links.
